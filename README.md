## 💡 ¿Por qué OpenCV Studio?

La inmensa mayoría de creadores de CV en línea permiten diseñar tu currículum de forma aparentemente gratuita, pero bloquean la descarga o cobran suscripciones automáticas abusivas al momento de exportar tu PDF. Además, almacenan tus datos personales, teléfonos y trayectoria laboral en servidores de terceros.

**OpenCV Studio** rompe con este modelo:
1. **100% Gratuito y Libre**: Desarrollado bajo licencia abierta MIT.
2. **Totalmente Offline y Seguro**: Funciona en tu computadora de manera autónoma. Ningún dato viaja por la red ni se envía a servidores externos.
3. **Diseñado para Superar Filtros ATS**: Cada plantilla ha sido auditada para garantizar que los analizadores automáticos de recursos humanos puedan extraer el 100% de tu información sin perder palabras clave ni desconfigurar formatos.
4. **Exportación Impecable**: Genera PDFs vectoriales listos para imprimir o enviar en postulaciones de empleo con un solo clic.

## 📥 Descarga e Instalación

### Opción 1: Ejecutable Portable para Windows (Recomendada)
No requiere instalación previa ni permisos especiales de administrador:

1. Ve a la sección de **[Último Lanzamiento (Releases)](https://github.com/CoriosMwRaw/opencv-studio/releases/latest)**.
2. Descarga el archivo comprimido **`OpenCV_Studio_Windows_x64.zip`**.
3. Descomprime la carpeta en cualquier ubicación de tu equipo (por ejemplo, en Documentos o en el Escritorio).
4. Ejecuta el archivo **`OpenCV Studio.exe`** (o `Iniciar_Aplicacion.bat`).
5. *(Nota: Si Windows SmartScreen muestra una advertencia preventiva por ser un software independiente nuevo, pulsa "Más información" y luego "Ejecutar de todas formas").*

---

### Opción 2: Para Desarrolladores (Código Fuente)

Si deseas clonar el proyecto, personalizar plantillas o colaborar en el desarrollo:

```bash
# 1. Clonar el repositorio
git clone https://github.com/CoriosMwRaw/opencv-studio.git
cd opencv-studio

# 2. Instalar dependencias
npm install

# 3. Ejecutar en modo desarrollo
npm start

# 4. Compilar binario nativo portable para Windows (.exe)
npm run build
```

## 🛠️ Arquitectura y Tecnologías

* **Runtime de Escritorio**: [Electron v33](https://www.electronjs.org/) (Chromium + Node.js nativo).
* **Motor de Parsing y Extracción**: Heurística propia basada en expresiones regulares avanzadas, validación cruzada de nombres, detección de viñetas multi-línea y descompresión nativa de documentos OpenXML (`word/document.xml`) mediante `yauzl`.
* **Frontend**: HTML5 semántico, CSS3 moderno (Flexbox, CSS Grid, variables dinámicas, animaciones HUD con Keyframes) y JavaScript Vanilla modular reactivo sin dependencias de frameworks pesados.
* **Motor de Impresión**: CSS `@media print` optimizado para páginas de tamaño estándar Carta / A4 con vectores nítidos a 300 DPI.
* **Internacionalización**: Módulo bilingüe (`i18n.js`) que traduce la interfaz y las secciones del currículum dinámicamente entre Español e Inglés.

## 🔒 Privacidad y Almacenamiento Local

* Todos tus datos se almacenan exclusivamente en el `localStorage` de tu propio equipo.
* Las fotografías de perfil se optimizan y comprimen localmente a 320×320 píxeles usando la API Canvas de HTML5 para garantizar un rendimiento ultrarrápido sin consumir memoria innecesaria.
