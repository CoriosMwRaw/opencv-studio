Why does Windows show a security warning when downloaded?
------------------------------------------------------------------------
OpenCV Studio is a 100% FREE, OFFLINE, and OPEN-SOURCE desktop tool.
Unlike commercial corporations that pay $400+/year for Microsoft code
signing certificates, free community software does not carry a paid
certificate.

Because of this, Windows Defender SmartScreen automatically displays a
preventive warning ("Windows protected your PC") on newly downloaded
binaries from the Internet (Mark-of-the-Web / Zone.Identifier).

The source code is 100% transparent and auditable on GitHub:
https://github.com/CoriosMwRaw/opencv-studio


HOW TO RUN IT IN UNDER 3 SECONDS? (Choose any method)
------------------------------------------------------------------------

METHOD 1 (FASTEST - RECOMMENDED):
  Double-click on:
  👉 "Unblock_and_Run.bat" (or "Abrir_OpenCV_Studio.bat")
  This script safely clears the Windows download flag and starts the app
  instantly with zero warnings.

METHOD 2 (FROM WINDOWS DEFENDER BLUE SCREEN):
  1. Double-click "OpenCV Studio.exe".
  2. When the blue "Windows protected your PC" dialog appears, click:
     "More info" (underlined link).
  3. Click the button at the bottom:
     "Run anyway".
  (You only need to do this once).

METHOD 3 (MANUAL UNBLOCK VIA PROPERTIES):
  1. Right-click on the ZIP file or "OpenCV Studio.exe".
  2. Select "Properties".
  3. At the bottom of the "General" tab, check the box:
     [✓] "Unblock".
  4. Click "OK" and launch the app normally.
